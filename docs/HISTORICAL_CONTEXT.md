# 精确年份与地点历史契约

主界面支持 1800 年至服务器当前年的每一个整数年份，默认 1926。`target_year` 是请求、推理、结果与缓存的权威年份，不再映射成四个年代锚点。旧 `1900s / 1920s / 1950s / 1970s` 请求继续分别解析为 1905 / 1925 / 1955 / 1975；旧回放从 `anchor_year` 读取年份。

只选年份无法确定年内转折的前后，因此统一声明 `reference_date = YYYY-07-01`。历史模型必须以这个时点判断当地状态，不能混合年初与年末场景，也不能把一个地区的战争或战后状态套用于所有城市。

## 位置与推理输入

地点优先级是明确手动覆盖、照片 EXIF GPS、设备 GPS、未知。手动地点只代表解析后的城市，并非街道或地块；同名城市需要州省/国家消歧。未解析的自由文本不进入模型。GPS、城市、州省、国家、定位来源与精度构成 `location_context`，会发送给历史推理和图像服务。离线地理解析只负责识别现今位置，不提供土地历史证据。

历史推理请求包含 `target_year`、`reference_date`、`location` 和 `present_day_scene`。当前场景描述建筑、道路、地貌和可见设施；不得先假定它们在历史上存在。K2 优先；未配置完整 K2 时可使用已配置的 Gemini 文本模型。网络错误、超时或结构校验失败会返回通用年份约束，明确标记未知历史。

## 冻结的历史输出

`constraints.historical_context` 保存：

| 字段 | 含义 |
|---|---|
| `target_year`, `reference_date` | 实际年份与明确参考时点 |
| `location` | 结构化现今地理位置，含精度与来源 |
| `period_summary` | 此地点、此年份的历史时期推测 |
| `local_context` | 当地事件和社会环境；区分年内转折 |
| `site_state` | `undeveloped / agricultural / built / mixed / unknown` |
| `site_history` | 此地块的开发与土地使用推测 |
| `reconstruction_changes` | 建筑、道路、设施的保留、移除或替换建议 |
| `uncertainties` | 位置精度、年内变化和史料缺失等限制 |
| `evidence_basis` | `model_knowledge_unverified` 或 `fallback` |

`era_facts` 是当地截至参考日期可用的交通、服饰、建材、照明等视觉条件，不再要求整个十年相同。历史文本允许出现年份、建成时间等数字。模型提供的历史内容属于未经检索验证的推测；当前系统没有接入地籍、历史地图或档案库，不声称能确认任意坐标的前身建筑。

## 图像生成

先完成历史推理，再生成锚点；锚点与所有瓦片共享完全相同的 `prompt_global`、日期和负向约束。每个瓦片不能单独猜测历史。

提示词明确固定相机位置、朝向、投影与完整画幅。建筑轮廓、高度、道路、人工天际线和地块用途允许变化：后来修建的建筑应移除，有依据的旧建筑可替代，未开发或农业用地可显示对应自然地貌或农田。不能仅把今天的建筑做旧；也不能在证据不足时擅自加入著名地标、战争破坏或荒地。城市级或未知位置强制 `site_state=unknown`，同时舍弃模型对具体地块的建筑替换指令，保留城市背景并使用通用视觉约束。

`fallback=true` 时，仍使用实际目标年份、地点精度、未知地块状态和完整几何政策，但不虚构确定的当地时期。前端展示历史摘要与不确定性。`demo` 始终离线，只用于交互和色调演示。

## 缓存与兼容

模型调用前的请求索引包含精确年份、地点、图像服务、360 选项及 `PROMPT_VERSION`。图像缓存键包含原始图片字节、精确年份、图像服务及完整提示词。旧版本缓存不自动作为新请求结果复用；现有回放仍可主动打开。不同年份或同城不同 GPS 不得互相命中。真实服务的历史推理降级结果不登记自动重放缓存，也不接受旧降级缓存；用户重试时会重新获取历史背景。音频可复用最接近的已有年代素材，但音频档位不参与历史推理。

# 世界生成质量

2026-09-12 调整 `/world/` 的新任务默认配置：

| 环节 | 原配置 | 当前配置 |
| --- | --- | --- |
| 世界生成 | 固定 `marble-1.0-draft` | 默认 `marble-1.1`，可显式选 Draft |
| 三维资源 | 最低点数，通常 100k | 优先 `full_res`，缺失时选最高可用点数 |
| 页面说明 | 未突出资源精度 | 显示实际模型、资源精度、点数与生成前费用 |

Marble 1.1 世界阶段为 1,500 credits（约 $1.20）；Draft 为 150 credits（约 $0.12）。Google 影像获取、历史图片编辑及需要时的全景生成另计。Marble 1.1 Plus 侧重更大的世界范围，不作为本次默认选项。[官方模型说明](https://docs.worldlabs.ai/api/faq)、[官方价格](https://docs.worldlabs.ai/api/pricing)

生成服务按所选模型的世界费用检查余额，计划和模型共同决定缓存身份。标准版不会命中旧 Draft 任务。旧任务按记录中的模型恢复；已有资源不会被自动改写或触发重新付费生成。回放页面标注实际精度，重新准备街景后可选择标准质量生成新版本。

完整精度需要更多下载、内存与 GPU 资源。原有 100 MiB 下载上限和文件校验保留；完整精度下载失败时任务暂停并显示错误，不静默换成低精度再称为高清。提供方未返回 `full_res` 时才选择最高可用点数，页面明确标为精简精度。

## 画面验收

配置升级消除了 Draft 默认值和最低点数下载这两项已知损失，不能保证模型每次都产出合格画面。SPZ 文件检查仅确认容器格式；`ready` 表示资产已保存，不代表视觉检查通过。

正式演示前，用同一份历史全景生成标准版并实际查看：

1. 在相同起始视角检查建筑边缘、道路和纹理是否清楚。
2. 环视一周，检查全景接缝、缺失区域、漂浮碎片和明显重复结构。
3. 在演示需要的范围内移动相机，检查视差、遮挡、空洞和空间拉伸。
4. 在目标手机上检查帧率与稳定性；历史年代和建筑变化另行结合资料审阅。

上游历史改图仍使用原有 `OPENAI_IMAGE_QUALITY` 配置；输入图的模糊、错误结构或年代偏差不会由高精度 SPZ 自动修复。本次进行了离线回归验证，尚未运行付费的 Marble 1.1 样本或完成新版画面验收。已有 Draft 的实测记录保留原结论。
